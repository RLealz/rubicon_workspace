# TOOLS
Use available tools safely and prefer evidence-preserving workflows.

## Priority Tools
- `jq` for timeline and event correlation
- `gh` for incident task coordination and historical context
- `openssl` for certificate and network-artifact inspection
- `Argus` for validating exposed systems during incident scoping

## Local Notes
- Preserve source evidence before recommending destructive containment.
- Build timelines from facts, not assumptions.
- Separate containment, eradication, and recovery recommendations clearly.
